# Luma Café ☕

A modern, responsive, multi-page café website created as part of my **Codveda Web Development Internship**.

Luma Café is a simple and welcoming café website designed to present the café, showcase its menu, share contact information, and provide visitors with an easy browsing experience.

## 🌟 Features

* **Home Page:** Introduces Luma Café with a welcoming layout and café imagery.
* **About Page:** Shares information about the café.
* **Menu Page:** Displays coffee, bakery favourites, and cold drinks with images and prices.
* **Contact Page:** Provides contact details, opening hours, and a demo contact form.
* **Responsive Design:** Adapts the layout to different screen sizes.
* **Navigation:** Allows visitors to move between the website's pages.
* **Clean Typography:** Uses stylish fonts for a polished appearance.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Visual Studio Code

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the `Luma-Cafe` folder.
3. Open `index.html` in your web browser.
4. Use the navigation menu to explore the other pages.

You can also open the project folder in Visual Studio Code to view and edit the source code.
